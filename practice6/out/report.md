## Обоснование параметров
| Параметр | Значение | Почему |
|---|---|---|
| YOLO | yolov8n.pt | Самая быстрая версия, отлично работает на CPU без видеокарты, достаточна для детекции крупных объектов (люди, мебель, посуда). |
| Порог conf | 0.4 | По графику `conf_sweep.png` видно, что при 0.25 слишком много ложных срабатываний, а при 0.6 теряются реальные объекты. 0.4 — золотая середина. |
| Whisper | tiny | Легкая модель (75 МБ), быстро работает на CPU. Для русского языка показывает достаточную точность распознавания бытовой речи. |
| Шаг кадров | 1 / 2 / 5 с | Динамический шаг: для коротких роликов (до 10 мин) — 1 кадр/сек, чтобы не пропустить события. Для длинных — реже, чтобы не перегружать процессор. |
| Громкость | z ≥ 2.0, не тише -35.0 dB | Защита от фонового шума. Событием считается только резкий скачок громкости выше среднего + 2 сигмы. |
| Смена сцены | корреляция гистограмм < 0.6 | Корреляция ниже 0.6 означает, что картинка кардинально изменилась (монтажный склейка). |
| Объект как событие | ≥ 3.0 с, пропуск ≤ 2.0 с | Объект считается событием, только если он задержался в кадре дольше 3 секунд (отсекаем случайные вспышки). |

## Ручная проверка
Результат `python3 validate.py --score` (случайные события, сверка с видео): 
**Проверено 5 случайных событий. Верно 4 из 5 (точность 80%).**
