# Практика 6. Автоматический анализ и семантическая обработка видеоданных

Сервис «для журналистов»: вводите слово (например, «ремонт») — получаете ролики, моменты в речи и кадрах, где это встречается, интерактивную временную шкалу событий и тематическую группировку роликов.

Проект реализует полный мультимодальный пайплайн: сбор видео и метаданных → декомпозиция (кадры, аудио) → детекция объектов (YOLO) → распознавание речи (Whisper) → извлечение событий → кластеризация по темам → визуализация.

## 2.Установка

1. Установите **ffmpeg** (системная утилита для видео и аудио):
   ```bash
   sudo apt update
   sudo apt install ffmpeg

Проверка: команды ffmpeg -version и ffprobe -version должны работать.

2. Создайте виртуальное окружение и активируйте его:
   ```bash
python3 -m venv venv
source venv/bin/activate

3. Установите PyTorch (только для CPU). Это важно, чтобы не скачивать 3 ГБ библиотек CUDA:
   ```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

4. Установите остальные зависимости:
   ```bash
pip install -r requirements.txt

## 3.Запуск
1. Впишите источники в sources.txt.
Примечание: из-за блокировок YouTube, скрипт может не скачать видео с него. Рекомендуется использовать Rutube или локальные файлы.
# Пример:
https://rutube.ru/video/ebc42ced8d6858b2ee7b29f3bde1e53e/
data/my_local_video.mp4

2. Запустите пайплайн:
   ```bash
python3 run_pipeline.py --sources sources.txt --whisper tiny
(Флаги: --whisper small, --conf 0.5, --method hdbscan, --skip-yolo, --skip-asr, --force, --stage collect|analyze|aggregate).
Повторный запуск пропустит уже обработанные файлы (кэш).

3. Откройте интерактивный дашборд:
Вместо ручного запуска сервера используйте утилиту:
   ```bash
python3 view_dashboard.py

Скрипт сам найдет свободный порт (8000 или 9000) и откроет браузер со страницей dashboard.html.

4. Поиск в консоли:
   ```bash
python3 search.py "ламинат"

5. Ручная проверка (валидация):
   ```bash
python3 validate.py --n 5

Откройте out/validation.csv, проверьте кадры/видео, поставьте 1 или 0 в колонку verdict.
   ```bash
python3 validate.py --score


## 4.Виды событий, особенности реализации, ограничения.

1. Виды событий:
    loud_peak (громкость ≥ среднее + 2σ)
    scene_change (корреляция HSV-гистограмм < 0.6)
    object (класс YOLO непрерывно ≥ 3 с)

2. Особенности реализации:
    Мультимодальность: аудио и кадры анализируются вместе. Шаг кадров рассчитывается динамически по fps каждого ролика, чтобы не забивать память.

    Обоснование порогов: YOLO пишет все детекции от conf 0.25, а для анализа применяется порог 0.4. Для доказательства правильности выбора генерируется график out/conf_sweep.png.

    Устойчивость к ошибкам:

        Если ролик недоступен (например, блокировка YouTube), он пропускается, а причина пишется в data/errors.csv.

        Если в ролике нет звука, это фиксируется в errors.csv, пайплайн не падает.

        Локальные файлы копируются под ASCII-именем, чтобы избежать проблем с кириллицей в путях на разных ОС.

    Веб-совместимость: Видео с Rutube могут иметь кодек MPEG-TS, который не играет в браузере. Пайплайн конвертирует их в H.264 при необходимости (встроенная логика FFmpeg).

    Этика: Эмоции и «внимание» по лицам не выводятся, соблюдаются этические ограничения (152-ФЗ).

3. Ограничения:
    Поиск в панели — по префиксу (5 букв), в консоли — по лемме (pymorphy3). Для идеального поиска нужна полноценная семантическая индексация (эмбеддинги).

    Соблюдайте условия использования платформ: берите небольшое число роликов (до 10) для учебных целей.
