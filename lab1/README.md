# Лабораторная работа 1 — Граф информационных ресурсов металлургии

Скрипт собирает текст с сайтов металлургической отрасли, извлекает ключевые
термины через `rutermextract` и строит **неориентированный граф** связей между
ресурсами через общие термины. Результат — файлы `.dot` и `.png`.

## Структура проекта

```
lab1/
├── lab1.py             — основной скрипт
├── sources.txt         — список URL (один на строку)
├── requirements.txt    — зависимости
├── README.md
├── .cache/             — кэш страниц (создается автоматически)
└── output/             — результаты (создается автоматически)
    ├── metallurgy_graph.dot
    ├── metallurgy_graph.png
    └── errors.json
```

## Системные требования

- Python 3.10+
- **Graphviz** (для рендера PNG):
  ```bash
  sudo apt install graphviz      # Debian/Ubuntu
  sudo dnf install graphviz      # Fedora
  brew install graphviz          # macOS
  ```

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**Важно:** `requirements.txt` фиксирует `setuptools<81`, иначе
`pymorphy2` (зависимость `rutermextract`) падает с `AttributeError`
на Python 3.11+.

## Запуск

```bash
python lab1.py
```

Без аргументов обработает все URL из `sources.txt` и сохранит результат
в `output/`.

## Аргументы CLI

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `--sources` | `sources.txt` | Файл со списком URL |
| `--output-dir` | `output` | Папка для результатов |
| `--cache-dir` | `.cache` | Папка для кэша страниц |
| `--terms` | 20 | Максимум терминов на ресурс |
| `--threshold` | 2 | Минимум общих терминов для связи |
| `--limit-sites` | 0 (все) | Ограничить число обрабатываемых сайтов |
| `--text-limit` | 100000 | Максимум символов текста на страницу |
| `--no-cache` | — | Отключить кэширование |

## Как изменить список сайтов

Откройте `sources.txt` и замените/добавьте URL — по одному на строку.
Строки, начинающиеся с `#`, игнорируются (можно использовать как комментарии).

Пример:
```
# Металлургические предприятия
https://www.severstal.com/
https://mmk.ru/

# Информационные порталы
https://www.metalinfo.ru/
https://metaltorg.ru/
```

Скрипт **автоматически дедуплицирует** записи по домену — если один и тот же
сайт указан дважды (с `www.` и без), обработается только первый.

## Примеры запуска

### Обработать все сайты из sources.txt
```bash
python lab1.py
```

### Быстрая проверка на первых 5 сайтах
```bash
python lab1.py --limit-sites 5
```

### Строгие связи: минимум 3 общих термина
```bash
python lab1.py --threshold 3
```

### Другой файл источников и папка результатов
```bash
python lab1.py --sources my_sources.txt --output-dir results
```

### Без кэша (полезно при отладке)
```bash
python lab1.py --no-cache
```

## Как это работает

1. **`sources.txt`** — читается список URL, пустые строки и комментарии
   игнорируются.
2. **Дедупликация** — убираются повторы по домену.
3. **Кэш** — при первом запуске страницы скачиваются и сохраняются
   в `.cache/`. **Ошибки тоже кэшируются** — повторный запуск
   не ждет таймаутов. Отключается флагом `--no-cache`.
4. **Извлечение текста** — `requests` + `BeautifulSoup`.
   Обрезка по `--text-limit` (по умолчанию 100 000 символов).
5. **Термины** — `rutermextract` извлекает ключевые слова.
   Отбрасываются стоп-слова (навигация, месяцы, дни недели).
   Максимум на ресурс — `--terms`.
6. **Граф** — `graphviz.Graph` (неориентированный).
   Связь между сайтами строится, если у них **≥ `--threshold`**
   общих терминов. На ребрах — до 3 общих терминов.
7. **Диагностика** — недостижимые сайты и сайты без терминов
   записываются в `output/errors.json`.

## Пример результата

По итогам обхода 30 URL:
- **19 сайтов** успешно обработаны
- **11 сайтов** недоступны (устаревшие, SSL-ошибки, блокировки)
- **25 связей** между сайтами построено (при `--threshold 2`)

Типичные связи:
```
metalinfo.ru -- metaltorg.ru        [label="цены, черные металлы"]
metalinfo.ru -- mc.ru               [label="москва, санкт-петербург"]
metaltorg.ru -- metallotorg.ru      [label="арматура, металлопрокат, цены"]
rusmet.ru    -- metalbulletin.ru    [label="цветные металлы, черные металлы"]
```

## Работа с кэшем

**Первый запуск** — программа скачивает страницы через сеть:
- Успешные сайты → текст в `.cache/`
- Недоступные → маркер ошибки в `.cache/`

**Повторный запуск** — все читается из кэша, время работы ~3 секунды
вместо ~80 секунд.

**Сброс кэша:**
```bash
rm -rf .cache
```

## Ограничения

- Без установленного **Graphviz** PNG не создастся, но `.dot` будет.
- `rutermextract` использует `pymorphy2`, которому нужен `setuptools<81`.
- Обход сайтов выполняется последовательно — при большом списке
  (`--limit-sites 100 --no-cache`) может занять время.
- В выводе таблицы показываются до 200 символов текста страницы.
- `--text-limit` по умолчанию 100 000 символов — для крупных сайтов
  потеряется конец страницы, но начало обычно содержит основные термины.
