# Практическая работа 1 — Поиск по архиву Common Crawl

Консольное приложение для поиска страниц в открытом веб-архиве
Common Crawl через CDX-индекс, с точечной загрузкой фрагментов
страниц из WARC-файлов.

## Структура проекта

```
practice1/
├── practice1.py       — основной скрипт
├── requirements.txt   — зависимости
└── README.md          — этот файл
```

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python practice1.py [ключевые-слова...] [--domain ДОМЕН...] [--limit N] [--show-text]
```

## Аргументы

| Аргумент | Тип | Описание |
|---|---|---|
| `keywords` | позиционные | Одно или несколько ключевых слов. Необязательно |
| `--domain` | опция | Домены. По умолчанию: `pstu.ru` |
| `--limit` | опция | Лимит **на каждый домен** (по умолчанию 10) |
| `--show-text` | флаг | Показать фрагмент текста страницы |

## Как это работает

1. **CDX-индекс** — лёгкий поиск метаданных: URL, дата архивации, offset и length.
   Отбор только `status:200` и `mime:text/html`.
2. **WARC-файл** — загрузка тела страницы точечно, через HTTP-заголовок
   `Range: bytes=offset-end`, без скачивания всего файла целиком.
3. **Фильтр по keywords** применяется к `title + text`. Работает всегда,
   когда заданы ключевые слова (независимо от `--show-text`).
4. **Парсинг HTML** — `BeautifulSoup`. Извлекаем `<title>` и чистый текст.
5. **Вывод** — таблица через `tabulate` + распределение по доменам и годам.

Используются 7 последних краулов Common Crawl (2024–2025).

## Примеры

### 1. Пермь и ПНИПУ
```bash
python practice1.py Пермь --domain pstu.ru --limit 10 --show-text
```

### 2. Кафедра ИТАС
```bash
python practice1.py ИТАС --domain pstu.ru --limit 10 --show-text
```

### 3. МГУ vs МФТИ
Запускать дважды и сравнить число строк и распределение по годам:
```bash
python practice1.py --domain msu.ru --limit 30
python practice1.py --domain mipt.ru --limit 30
```

Или за один запуск:
```bash
python practice1.py --domain msu.ru mipt.ru --limit 30
```

### 4. Борис Пастернак + Пермь
```bash
python practice1.py Пастернак --limit 20 --show-text
```
Примечание: если запустить с двумя словами
(`Пастернак Пермь`), программа вернёт только страницы, где встречаются
**оба** слова одновременно. Это может дать мало результатов — по
аналогии с проверкой на конкретных доменах.

### 5. Без указания домена (используется `pstu.ru` по умолчанию)
```bash
python practice1.py Пермь --limit 5
```

## Что выводится

1. **Таблица**: `URL | Дата архивации | Заголовок страницы`
   (+ `Фрагмент текста` при `--show-text`)
2. Общее число найденных строк
3. Распределение по доменам
4. Распределение по годам

## Особенности

- `--limit` применяется **отдельно к каждому домену**.
  `--domain msu.ru mipt.ru --limit 30` → до 60 записей (30 + 30).
- Заголовок страницы извлекается **всегда**, независимо от флагов.
- При заданных keywords выборка автоматически увеличивается в 2 раза —
  чтобы после фильтрации осталось примерно `--limit` записей.
- Retry-логика: 3 попытки при HTTP 502/504 с экспоненциальной задержкой.
- Обработка ошибок WARC: если один файл недоступен (503/404),
  программа продолжает работу с остальными.
- IPv4-патч: принудительно используется только IPv4, чтобы избежать
  таймаутов на сетях с неработающим IPv6.

## Ограничения

- CDX API имеет rate limit — при частых запросах возможны 502/504.
- WARC загружается по одному. При `--limit 100 --show-text` это займёт время.
- В выводе показываются первые 200 символов текста страницы (полный
  текст — 30 000 символов — хранится в объекте, но не выводится).
- Обрабатываются только HTML-страницы (фильтр `mime:text/html` в CDX).
- Обход только тех краулов, что перечислены в `INDEX_URLS` (7 последних).
