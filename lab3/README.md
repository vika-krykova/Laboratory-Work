# Лабораторная работа №3 - Wikimedia API

Автоматизированный сборщик данных из проектов Wikimedia по теме запроса.
Работает с Википедией, Викидатой, Викисловарем и Wikimedia Commons.

## Установка

1. Создание виртуального окружения и его активация:

```bash
python3 -m venv venv
source venv/bin/activate  	# Linux/macOS
venv\Scripts\activate     	# Windows
```

2. Установка зависимости:

```bash
pip install -r requirements.txt
```

## Запуск:

```bash
python lab3.py <запрос> [опции]
```

### Аргументы:

- `query` - тема запроса (личность, объект, событие, животное). Обязательный.
- `--lang` - язык проектов, по умолчанию `ru`. Можно указать `en` или другой.
- `--depth` - минимум статей в графе, по умолчанию 30.
- `--outdir` - папка для результатов, по умолчанию `output`.
- `--potd` - скачать картинку дня (Picture of the Day) из Commons.
- `--no-wiktionary` - пропустить обращение к Викисловарю.

### Примеры

```bash
# Базовый запуск
python lab3.py "Лев Толстой"

# С картинкой дня и глубиной графа 40
python lab3.py "космос" --depth 40 --potd

## Как работает:

Приложение последовательно обращается к API четырех проектов Wikimedia:

1. **Wikipedia API** - поиск статьи по запросу, загрузка текста, гиперссылок, изображений и внешних ссылок.
2. **Wikidata API** - поиск сущности по названию статьи, получение метки, описания и доп. ссылок.
3. **Wiktionary API** - поиск словарной статьи по последнему слову запроса.
4. **Wikimedia Commons API** - поиск до 10 изображений по теме.
5. **BFS-обход по гиперссылкам** - сбор `--depth` статей, начиная с корневой. Для каждой сохраняются ее ссылки.
6. **Picture of the Day** - через Wikimedia Feed API скачивается картинка дня и ее описание в текстовый файл рядом.

## Выходные файлы:

Все результаты сохраняются в папке `output/`:

- `result.json` - основной JSON-файл:
  - `wikipedia.main_article` - основная статья (текст, ссылки, изображения);
  - `wikipedia.related_articles` - список связанных статей (30 штук);
  - `wikidata` - сущность из Викидаты;
  - `wiktionary` - словарная статья;
  - `commons.files` - список изображений.
- `graph.dot` - граф связей между статьями в формате DOT.
- `<имя файла картинки>` - картинка дня (при флаге `--potd`).
- `<имя файла картинки>.txt` - описание картинки дня.

## Граф связей:

Граф - направленный: ребро `A → B` строится, если статья `B` упоминается в гиперссылках статьи `A`. Всего в графе минимум 30 вершин (узлов-статей).

Визуализация через Graphviz:

```bash
dot -Tpng output/graph.dot -o output/graph.png
```

## Ограничения:

- **Rate limit.** Wikimedia ограничивает частоту запросов. При превышении API возвращает 429 - скрипт ждет и повторяет до 5 раз.
- **Обрезка текста.** Текст основной статьи сохраняется до 5000 символов, связанных - до 500. Полный текст доступен по URL статьи.
- **Картинка дня** требует заголовок `Referer: https://commons.wikimedia.org/` при скачивании - добавлено в код.
- **Викисловарь.** Для запроса из нескольких слов ищется только последнее слово (словарные статьи хранят леммы, а не имена собственные).
- **Диагностика.** Если часть статей не удалось загрузить при обходе, программа выведет `не удалось загрузить: N статей`.
