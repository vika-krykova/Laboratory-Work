# Практика 7: Рекомендательная система для медиакаталога

Проект реализует полный пайплайн построения и сравнения рекомендательных систем на реальных данных.

Реализованы три подхода:
1. **Контентный** (content-based): TF-IDF по описаниям, жанрам и тегам + косинусное сходство.
2. **Коллаборативный на явных данных**: SVD (библиотека `surprise`).
3. **Коллаборативный на неявных данных**: ALS / BPR (библиотека `implicit`).

Обязательный элемент: сравнение всех моделей с бейзлайном "Популярное" (popular), а также оценка метрик ранжирования, покрытия каталога и разнообразия выдачи.

## Установка

1. Создайте виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```
Если `scikit-surprise` не ставится из-за конфликта с версией numpy, установите его в отдельном окружении или соберите из исходников: `pip install scikit-surprise --no-binary scikit-surprise`.

3. Скачайте датасеты:
* **MovieLens (ml-latest-small)**: https://files.grouplens.org/datasets/movielens/ml-latest-small.zip. Распакуйте в `data/ml-latest-small`.
* **Last.fm HetRec 2011**: https://files.grouplens.org/datasets/hetrec2011/hetrec2011-lastfm-2k.zip. Распакуйте в `data/hetrec2011-lastfm-2k`.

Датасеты предоставлены GroupLens Research для некоммерческих и исследовательских целей.

## Запуск

Все вычисления выполняются через CLI-скрипт `recsys.py`.

### Аргументы
* `--dataset`: `movielens`, `lastfm` или `amazon`.
* `--path`: путь к папке с датасетом.
* `--model`: `popular`, `content`, `svd`, `als`, `bpr`, список через запятую или `all`.
* `--k`: значения K для метрик (например, `--k 5 10`).
* `--evaluate`: рассчитать метрики (без флага скрипт только выгружает рекомендации в `recs.json`).
* `--eda`: построить графики разведочного анализа.
* `--mmr`: значения λ для переранжирования MMR (например, `--mmr 0.5 0.7 0.9`).
* `--segment-threshold`: граница "легких" и "тяжелых" пользователей по числу train-взаимодействий (по умолчанию медиана).
* `--seed`: seed (по умолчанию 42).
* `--output`: папка для результатов.

### Примеры

MovieLens (все модели, EDA, MMR):
```bash
python recsys.py --dataset movielens --path data/ml-latest-small --model all --k 5 10 --eda --evaluate --mmr 0.5 0.7 0.9 --output results/ml
```

Last.fm (неявные данные, без SVD):
```bash
python recsys.py --dataset lastfm --path data/hetrec2011-lastfm-2k --model popular,content,als --k 10 --evaluate --output results/lastfm
```

Юнит-тесты метрик:
```bash
python -m pytest tests -q
```

## Протокол оценки

* **Фильтрация (k-core):** удалены пользователи и объекты с менее чем 5 взаимодействиями; дубликаты пар "пользователь–объект" схлопнуты.
* **Сплит (поюзерный):**
  * MovieLens — хронологический: последние 5 взаимодействий пользователя в тест.
  * Last.fm — случайный leave-N-out (5 взаимодействий, фиксированный seed), так как в данных нет времени прослушиваний.
  * Пользователи с историей менее 10 взаимодействий остаются в train и в оценку не входят.
* **Релевантность:** MovieLens — рейтинг ≥ 4; Last.fm — любое прослушивание.
* **Оценка:** ранжирование по всему каталогу за вычетом объектов из train; метрики Precision@K, Recall@K, MAP@K, NDCG@K, покрытие каталога, разнообразие выдачи (intra-list diversity в пространстве TF-IDF), новизна, число жанров в списке.
* **Сегментация:**  метрики считаются в целом и отдельно для "легких" и "тяжелых" пользователей; граница - медиана числа train-взаимодействий (60 для MovieLens, 36 для Last.fm).
* **Значимость:** для метрик рассчитан 95% доверительный интервал (`ci95`); если интервалы моделей пересекаются, различие считается статистически незначимым (консервативный критерий).
* **Воспроизводимость:** seed = 42, версии библиотек: scikit-surprise 1.1.5, implicit 0.7.3, numpy 2.2.6.

## Результаты

Артефакты запусков сохраняются в `results/`: `metrics.csv` (модель × метрика × K × сегмент), `recs.json` (рекомендации для выборки пользователей), `eda.json` и `eda.png`, `coverage.png`, `cases.md` (материал для ручного разбора), `run_log.json` (версии, seed, размеры данных, время обучения). Полное описание и таблицы — в `Отчет.pdf`.

**Ключевые выводы**

1. **MovieLens (явные данные)**
   * SVD значимо хуже бейзлайна (MAP@10 0,0080 против 0,0234): он оптимизирует предсказание оценки (RMSE), а не ранжирование.
   * ALS (MAP@10 0,0288) по точности не отличим от бейзлайна (доверительные интервалы пересекаются), но дает на порядок большее покрытие каталога (22,0% против 2,9%).
   * Контентная модель самая слабая: жанровые признаки слишком грубые, выдача самая однородная.
2. **Last.fm (неявные данные)**
   * ALS значимо превосходит и бейзлайн, и контентную модель (MAP@10 0,0733).
   * Покрытие popular — 0,9%: в выдачах всех пользователей вместе встречается около 28 разных артистов.
3. **MMR (контентная модель, MovieLens)**
   * Разнообразие растет (ILD с 0,288 до 0,373, число жанров в списке с 6,85 до 7,82); изменение точности лежит в пределах доверительного интервала.

## Ограничения

* **Гиперпараметры:** число факторов (50) и итераций взято по умолчанию; подбор на валидационной выборке не проводился.
* **Холодный старт:** не тестировался (после k-core фильтра в данных нет новых пользователей и объектов).
* **Сплит на Last.fm:** случайный, без времени; метрики могут быть завышены.
* **Значимость:** проверялась по пересечению доверительных интервалов, без парного теста или bootstrap.
* **Разнообразие:** считается в том же TF-IDF-пространстве, в котором работают контентная модель и MMR, поэтому смещено в их пользу.
* **Ручной разбор:** выполнен для четырех пользователей и носит иллюстративный характер.
